# **PERSONAL LIBRARY MANAGER**

### This is a python program that runs a simple library manager. 


## SETUP
**Install Python**

You can install the python installer from the official python website at https://python.org/downloads


**Clone Repo**
```bash
git clone https://github.com/d3khan/personal-library-manager/
```

**Unzip and Run**

Unzip the cloned repo and enter the folder

```bash
cd personal-library-manager
```

Then run the program
```bash
python main.py
```

## INFO
1. This program stores the data over time
2. It uses OOP instead of dictionsaries
3. Objects are converted to lists and dictionaries to be stored in json format and are converted back
